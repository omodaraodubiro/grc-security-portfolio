## AWS IAM & S3 Access Control Governance Evaluation

## Project Objective
This project evaluates how AWS IAM identity-based policies and S3 resource-based policies interact to define effective access control boundaries. The objective was to analyze permission behavior, role assumption impact, and governance implications within a controlled AWS lab environment.
## Governance Focus
This project focuses on:

Principle of least privilege

Role-based access control (RBAC)

Policy evaluation logic (identity vs resource policies)

Trust relationships and role assumption

Access boundary misconfiguration risk
