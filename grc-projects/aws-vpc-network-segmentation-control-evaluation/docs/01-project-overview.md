## 1. Project Objective

The objective of this evaluation was to assess the security posture of a segmented AWS VPC environment and implement control improvements aligned with:

- Least Privilege Principle

- Zero Trust Network Segmentation

- Defense-in-Depth Strategy

- Secure Administrative Access Governance

This lab simulation mirrors real-world cloud governance responsibilities within enterprise environments.

## 2. Environment Overview

The environment contained:

- One VPC (10.0.0.0/16)

- Public Subnets

- Private Subnet

- AppServer (private)

- ProxyServer1 & ProxyServer2 (public)

- Bastion Host

- NAT Gateway

- Internet Gateway

- Security Groups

- Network ACLs
